# Jarvis Assistant - Android Native (Fase 1: Fundação)

Aplicativo oficial Jarvis construído com Clean Architecture + MVVM, Jetpack Compose, Material 3, Room Database, Preferences DataStore e abstração multi-provedor de IA.

## 📱 Como Baixar o APK para o Celular
1. Acesse a aba **[Releases](https://github.com/bulacha-productions/Jarvis/releases)** ou a aba **[Actions](https://github.com/bulacha-productions/Jarvis/actions)**.
2. Na Release mais recente, toque em **app-debug.apk** para baixar diretamente no seu smartphone.
3. Abra o arquivo no Android e toque em **Instalar**!
